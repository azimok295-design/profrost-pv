ПРОФРОСТ-PV — КАК ОПУБЛИКОВАТЬ САЙТ
=====================================

ВАЖНО: Это полноценный сайт с сервером и базой данных. Для работы тестов,
аккаунтов и результатов нужен хостинг приложения и PostgreSQL.
Не загружайте только index.html на Netlify — тогда система не заработает.

САМЫЙ ПОНЯТНЫЙ ПУТЬ: GITHUB + RAILWAY
--------------------------------------

ШАГ 1. Распакуйте ZIP
1) Найдите profrost-pv-platform.zip на компьютере.
2) Нажмите правой кнопкой мыши → «Извлечь всё».
3) Откройте сайт github.com и войдите или создайте аккаунт.

ШАГ 2. Создайте хранилище файлов на GitHub
1) Нажмите зелёную кнопку New (или плюсик справа сверху → New repository).
2) Название: profrost-pv-platform
3) Выберите Private (рекомендуется) или Public.
4) Нажмите Create repository.
5) На странице репозитория нажмите Add file → Upload files.
6) Откройте распакованную папку profrost-pv-platform на компьютере.
7) Выделите ВСЕ файлы и папку public внутри неё и перетащите в окно GitHub.
   Важно: загрузите содержимое папки, а не сам ZIP и не внешнюю папку целиком.
8) Нажмите Commit changes.

ШАГ 3. Запустите приложение на Railway
1) Откройте railway.com и зарегистрируйтесь/войдите.
2) Нажмите New Project → Deploy from GitHub Repo.
3) Подключите GitHub, если Railway попросит, и выберите profrost-pv-platform.
4) В проекте Railway нажмите New → Database → PostgreSQL.
5) Откройте сервис приложения → Variables и добавьте:

   NODE_ENV       production
   SESSION_SECRET длинная случайная строка не менее 32 символов
   ADMIN_NAME     Администратор ПрофРост-PV
   ADMIN_EMAIL    ваш рабочий email
   ADMIN_PASSWORD придумайте новый сложный пароль (не используйте пример)
   CENTER_NAME    ПрофРост-PV

6) Добавьте переменную DATABASE_URL из PostgreSQL:
   - откройте сервис PostgreSQL → Variables;
   - скопируйте значение DATABASE_URL или добавьте в сервис приложения
     ссылку на переменную PostgreSQL через Railway Reference.
   - Важно, чтобы переменная DATABASE_URL была доступна именно сервису приложения.
7) Дождитесь успешного Deploy.
8) Откройте Settings → Networking → Generate Domain.
9) Перейдите по выданной ссылке. Это адрес вашего сайта.

ШАГ 4. Первый вход
1) Откройте сайт по публичной ссылке.
2) Войдите через email из ADMIN_EMAIL и пароль из ADMIN_PASSWORD.
3) Сразу после проверки смените пароль, если в дальнейшем добавите такую функцию;
   не передавайте пароль обучающимся.
4) В панели администратора создайте свои тесты и вопросы.
5) Чтобы назначить закрытый тест, обучающийся сначала должен зарегистрироваться.
   Затем введите его email в блоке «Назначить закрытый тест».

КАК ВЫДАЁТСЯ СЕРТИФИКАТ
-----------------------
После успешной сдачи теста откройте «Мои сертификаты» → «Скачать PDF».
В окне печати выберите «Сохранить как PDF».

ПЕРЕД РАБОТОЙ С РЕАЛЬНЫМИ ОБУЧАЮЩИМИСЯ
--------------------------------------
- Используйте только свой уникальный пароль администратора и SESSION_SECRET.
- Настройте резервное копирование PostgreSQL.
- Добавьте на сайт политику конфиденциальности и согласие на обработку персональных данных.
- Проверьте применимые требования законодательства Республики Казахстан о персональных данных.
- Проведите тестовую регистрацию, тестирование и скачивание PDF.
- Хостинг и домен могут быть платными; проверьте тарифы Railway перед публикацией.

ЕСЛИ НЕ ПОЛУЧАЕТСЯ
------------------
Пришлите скриншот страницы, на которой остановились. Не отправляйте в чат
пароли, DATABASE_URL, SESSION_SECRET или другие секретные значения.
