# ПрофРост-PV — учебная платформа

Полноценный стартовый проект: открытые и закрытые тесты, регистрация обучающихся, роли администратора и обучающегося, назначения тестов, результаты, PDF-сертификаты через печать браузера.

## Функции

- Регистрация обучающихся по ФИО, email и паролю.
- Вход и выход; роли `admin` и `student`.
- Каталог открытых тестов.
- Закрытые тесты, видимые обучающемуся только после назначения администратором.
- Создание тестов с несколькими вопросами и вариантами ответов.
- Настройка времени теста и проходного балла.
- Автоматическая проверка ответов и история результатов.
- PDF-сертификат для успешно сданных тестов (кнопка открывает диалог печати; выберите «Сохранить как PDF»).
- Администратор видит пользователей, тесты и результаты.

## Локальный запуск

Требуется Node.js 20+ и PostgreSQL 14+.

1. Создайте базу PostgreSQL.
2. Скопируйте `.env.example` в `.env` и укажите `DATABASE_URL`, секрет сессии и пароль администратора.
3. Установите зависимости: `npm install`.
4. Запустите: `npm start`.
5. Откройте `http://localhost:3000`.

## Переменные окружения

- `DATABASE_URL` — строка подключения PostgreSQL.
- `SESSION_SECRET` — длинная случайная строка.
- `ADMIN_NAME` — имя администратора.
- `ADMIN_EMAIL` — email администратора.
- `ADMIN_PASSWORD` — первоначальный пароль администратора (минимум 12 символов рекомендуется).
- `CENTER_NAME` — название в сертификате.
- `NODE_ENV=production` — для production cookie.
- `PORT` — порт (обычно задаёт хостинг).

При первом запуске автоматически создаётся администратор и демонстрационный открытый тест. Измените пароль администратора после первого входа. Не используйте демонстрационный пароль в публичном интернете.

## Публикация на Railway

1. Создайте аккаунт GitHub и новый пустой репозиторий.
2. Загрузите содержимое этой папки в репозиторий (не загружайте `.env` и `node_modules`).
3. На Railway создайте новый проект → Deploy from GitHub Repo и выберите репозиторий.
4. Добавьте PostgreSQL: New → Database → PostgreSQL.
5. В настройках сервиса добавьте переменные:
   - `DATABASE_URL` — используйте ссылку PostgreSQL из Railway (обычно можно выбрать переменную `DATABASE_URL` через Reference).
   - `SESSION_SECRET` — длинная случайная строка.
   - `ADMIN_NAME` — Администратор ПрофРост-PV.
   - `ADMIN_EMAIL` — ваш рабочий email.
   - `ADMIN_PASSWORD` — придумайте новый сложный пароль.
   - `CENTER_NAME` — ПрофРост-PV.
   - `NODE_ENV` — production.
6. Railway запускает `npm start` автоматически. В Settings → Networking создайте публичный домен.
7. Откройте адрес сайта и войдите как администратор.

## Важно перед публичным запуском

Это рабочая основа, но перед использованием с реальными персональными данными рекомендуется:
- настроить резервное копирование PostgreSQL;
- включить HTTPS (Railway обеспечивает его на выданном домене);
- использовать уникальный сложный `SESSION_SECRET` и пароль администратора;
- добавить политику конфиденциальности и согласие на обработку персональных данных;
- проверить требования законодательства Казахстана по персональным данным и хранению данных;
- протестировать восстановление доступа и процессы выдачи сертификатов.

## Управление тестами

Администратор → «Администрирование»:
- создайте тест, добавьте вопросы и правильные ответы;
- выберите «Открытый» или «Закрытый (по назначению)»;
- чтобы назначить закрытый тест, у обучающегося уже должна быть учётная запись; укажите его email и тест в форме «Назначить закрытый тест».

Для PDF-сертификата обучающийся открывает «Мои сертификаты» → «Скачать PDF» → в окне печати выбирает «Сохранить как PDF».
